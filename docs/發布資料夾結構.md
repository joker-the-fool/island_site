# 福華名品島嶼網頁：發布資料夾結構說明

版本 1.0（2026-11-20）。本文件說明「發布資料夾」（本機 `ISLAND\`，同時也是 GitHub 倉庫 `island_site` 的內容）裡每個資料夾和檔案的用途。

- 網頁是純靜態檔案：不需要後端、不需要建置，用瀏覽器開 `index.html` 即可執行。
- 全部使用相對路徑，放在本機任何位置，或放在 GitHub Pages 的子路徑下都能運作。
- 線上網址：<https://joker-the-fool.github.io/island_site/>
- 建築、人物的寫法規範見同資料夾的 [模型規範.md](模型規範.md)，本文件不重複。

---

## 1. 整體結構

```
ISLAND\
├─ index.html            網頁本體（畫面、樣式、載入流程）
├─ manifest.js           要載入哪些 js、載入順序
├─ islands_data.js       島嶼資料（有幾座島、位置、橋、人物、跳轉頁面）
├─ logo_data.js          商場 LOGO 圖片資料
├─ maintain_tool.html    維護工具（編輯島、設定外觀與 LOGO）
├─ js\                   核心程式（場景、島、鏡頭與點擊、天空等）
├─ shapes\               建築模型（每個檔案一種建築）
├─ characters\           島上人物（每個檔案一個人物）
├─ creatures\            生物與小人（魚、海鷗、橋上走動的小人）
├─ pages\                點島後跳轉的內容頁
├─ vendor\               第三方函式庫（three.js）
└─ docs\                 文件
```

---

## 2. 根目錄的檔案

| 檔案 | 用途 | 誰會改它 |
|---|---|---|
| `index.html` | 網頁本體：畫面版面、樣式（品牌紅＋白底）、標題文字、「全部小島」按鈕與縮放條，並負責載入 `manifest.js` 列出的所有 js。 | 改網頁標題、副標、外觀時（多半用維護工具改，不手改） |
| `manifest.js` | 載入清單 `window.ISLAND_SCRIPTS`：依序列出所有要載入的 js。順序不能亂（核心 → 場景 → 建築 → 人物 → 島 → 群島 → 生物 → 天空 → 主程式）。新增建築或人物，就是在這裡加一行檔名。 | 新增或移除建築、人物時，手動加一行 |
| `islands_data.js` | 島嶼資料 `window.ISLANDS`（JSON 陣列）。每座島有：`id`、`title`、`desc`、`link`、`color`、`shape`、位置 `x`／`z`、`bridges`（橋連到哪些島）、`characters`（島上人物與位置），可選 `scale`、`seed`。另外含網頁外觀設定（標題、副標、字型、顏色）。 | 維護工具「儲存到檔案」會整份重寫，**不要手改** |
| `logo_data.js` | `window.MALL_LOGO`：商場 LOGO 圖片，以 data URL 文字存放，貼在商場建築圓形立面上。 | 維護工具「商場 LOGO」按鈕產生，**不要手改** |
| `maintain_tool.html` | 維護工具：拖曳島的位置、連橋、編輯島的屬性與島上人物、設定網頁外觀、產生 LOGO 資料、預覽。需用 Edge／Chrome 開啟。 | — |

### 為什麼 LOGO 和資料都是 `.js`，不是 `.png`、`.json`

用 `file://`（雙擊開檔）時，瀏覽器不允許網頁讀取本機的圖片或 JSON 當資料（跨來源限制），但允許載入 `.js`。所以資料一律包成 `window.XXX = ...` 的 js 檔，圖片轉成文字存進 js。放到 GitHub Pages（https）時也一樣能用。

## 3. `js\`：核心程式

這些是網站運作的骨幹，通常不需要改。

| 檔案 | 用途 |
|---|---|
| `core.js` | 最先載入：讀取島嶼資料、預覽模式（`?preview=`）、共用的基本積木函式（`mk`、`boxM`、`cylM`、`sphM` 等）、建築與人物的登記表（`ISLAND_SHAPES`、`ISLAND_CHARACTERS`）。 |
| `scene.js` | 場景：算圖器、鏡頭、燈光、海面。 |
| `island.js` | 島：位置、島本體（沙、草、浪花）、周圍的樹、名稱標籤、橋；並依 `shape` 呼叫對應建築、依 `characters` 放置人物。 |
| `satellites.js` | 遠處的無名群島（純裝飾，不在 `islands_data.js` 裡）。 |
| `sky.js` | 天空：低多邊形白雲與氣流線。 |
| `main.js` | 主程式，最後載入：海水深淺、鏡頭操作、點擊與跳轉、縮放條、主動畫迴圈。 |

### 操作行為（`main.js`）

- 單擊島：鏡頭飛過去聚焦。
- 再點一下**已聚焦**、且有設 `link` 的島：跳轉到 `link` 指定的頁面。
- 輕點兩下、第二下不放開直接拖：平移鏡頭（給只有單點觸控的 POS 用）。
- 網址加 `#島的id`（例如 `index.html#mall`）：載入後直接飛到該島。
- 網址加 `?preview=建築類型&color=%23rrggbb`：只顯示單一座島（維護工具預覽用）。

## 4. `shapes\`：建築模型

每個檔案登記一種建築到 `ISLAND_SHAPES`，檔名 = 登記名稱 + `.js`。`islands_data.js` 的 `shape` 欄位用這個名稱指定。維護工具的建築選單會自動列出所有已登記的建築。

舉例：

| 檔案 | 建築 |
|---|---|
| `mall.js` | 商場（紅磚主塔、裙樓、圓形 LOGO 立面） |
| `cinema.js` | 電影院（霓虹招牌、屋頂膠捲吉祥物） |
| `server.js` | 伺服器機櫃（LED 燈閃爍） |
| `isle_lighthouse.js`、`isle_pool.js`、`isle_nature.js` | 小島型建築（副島，標題留空就不顯示標籤） |

其餘（`reception`、`toy`、`pavilion`、`crystal`、`fashion`、`house`、`tower`）同樣是一檔一種建築。新增建築的寫法見 [模型規範.md](模型規範.md)；範例見 [範例_檸檬水攤.js](範例_檸檬水攤.js)。

## 5. `characters\`：島上人物

每個檔案登記一個人物到 `ISLAND_CHARACTERS`。人物放在哪座島、什麼位置，由 `islands_data.js` 的 `characters` 欄位決定（`type`＝人物名稱，`x`、`y`、`z` 相對於島，`ry` 為面向角度），人物檔本身不寫死位置。

| 檔案 | 人物與動作 |
|---|---|
| `hostess.js` | 迎賓女服務員：橋上小人走近，就鞠躬 |
| `serverman.js` | 眼鏡西裝男：小人走近，就舉左手推眼鏡，鏡片反光 |

人物的外觀可以由模型編輯器匯出；動作（走近才觸發）是寫在人物檔最後的 `ctx.onUpdate`，編輯器匯出的檔案不含動作，需要另外補上。

## 6. `creatures\`：生物與小人

自成一體的動畫生物，不屬於任何一座島。

| 檔案 | 用途 |
|---|---|
| `fish.js` | 跳出水面的魚，含落水水波 |
| `seagull.js` | 繞著島盤旋的海鷗 |
| `walker.js` | 橋上來回走動的小人（每座橋兩個，島上人物是否鞠躬、推眼鏡就看他們有沒有走近） |

## 7. `pages\`：跳轉內容頁

點島跳轉時開啟的內容頁，對應 `islands_data.js` 裡各島的 `link` 欄位（例如 `"link": "pages/data.html"`）。

| 檔案 | 用途 |
|---|---|
| `data.html`、`docs.html`、`hub.html`、`lab.html`、`poweroff.html`、`replace.html`、`report.html`、`tools.html`、`update.html`、`version.html` | 目前是簡單的範本頁，每頁有「← 回到島嶼」連結（指向 `../index.html#島的id`），回去時會直接飛到該島。內容之後可以自行替換。 |

新增內容頁：在此放一個 html，再到維護工具把島的「跳轉頁面」填成 `pages/檔名.html`，存檔。

## 10. 資料流程總覽

```
開啟 index.html
  ├─ 載入 manifest.js → 依序載入 js\ → shapes\ → characters\ → creatures\ …
  ├─ 載入 islands_data.js → 得到島的清單
  ├─ 載入 logo_data.js → 商場 LOGO
  └─ main.js 建立畫面：依每座島的 shape 呼叫建築、依 characters 放人物、依 bridges 連橋

維護工具（maintain_tool.html）
  └─ 「儲存到檔案」→ 寫入 islands_data.js
  └─ 「商場 LOGO」→ 寫入 logo_data.js
  └─ 「開啟完整畫面」→ 用目前尚未存檔的設定預覽 index.html
```

## 11. 更新與發布

- 本機：用維護工具編輯後，按「儲存到檔案」，並在選資料夾時選這個發布資料夾。
- GitHub：發布資料夾本身就是倉庫 `island_site`（GitHub Pages，`main` 分支根目錄）。檔案更新後提交並推送，約一兩分鐘後線上網站更新。
- 注意檔名大小寫：GitHub 伺服器區分大小寫，`manifest.js` 裡的檔名必須和實際檔名完全一致。
- 新增建築或人物：把檔案放進 `shapes\` 或 `characters\`，再到 `manifest.js` 加一行（必須在 `'js/island.js'` 之前）。
